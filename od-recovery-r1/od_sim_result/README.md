# Simulation Results

This directory contains outputs generated by the simulation and OD
reconstruction pipeline.

---

## Contents

When the pipeline is executed, this folder may include:

- Reconstructed multimodal OD flow matrices

File names and exact contents depend on the experimental configuration
and selected model parameters.

---

## Reproducibility notes

- All files in this directory are **generated outputs**.
- Results can be fully regenerated by running the notebooks in
  `sim_notebooks/` in the documented execution order.
