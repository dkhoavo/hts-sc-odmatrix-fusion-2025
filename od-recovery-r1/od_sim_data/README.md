# Simulation Data Directory

This directory stores simulation inputs generated by
`sim_notebooks/00_prepare_sim_data.ipynb`.

---

## Data availability

Raw household travel survey (HTS) microdata are **not publicly distributed**
due to privacy and data-sharing agreements. Due to the size and access restrictions of the HTS microdata, only
**origin–destination (OD) information is used in the simulation**, and
departure-time information is intentionally excluded.

As a result:
- Files named `data_hts_{reg}.csv` (reg ∈ {seoul}) are **not included**
- Notebook `00_prepare_sim_data.ipynb` is provided for transparency only

---

## Exported simulation files

When generated locally, this directory contains the following files
(for each region `reg`):

### Contextual and prior information

- `data_sim_{reg}_destination_lu_mix.csv`  
  Destination-level land-use mixture features derived from HTS trip purposes.

- `data_sim_{reg}_prior_origin_vh.csv`  
  Origin-level prior distribution for private-vehicle (VH) trips.

- `data_sim_{reg}_prior_origin_wk.csv`  
  Origin-level prior distribution for walking (WK) trips.

- `data_sim_{reg}_prior_destination_vh.csv`  
  Destination-level prior distribution for private-vehicle (VH) trips.

- `data_sim_{reg}_prior_destination_wk.csv`  
  Destination-level prior distribution for walking (WK) trips.

---

### OD flow data

- `data_sim_{reg}_sc.csv`  
  Smart-card proxy OD data containing **public-transport (PT) trips only**,
  with OD attributes and trip distance.

- `data_sim_{reg}_true.csv`  
  Ground-truth multimodal OD matrix aggregated from HTS, containing
  PT, WK, and VH trip counts for each OD pair.

---

### HTS subsamples

- `data_sim_{reg}_hts_v{i}.csv`,  where `i = 1, …, 5`  

  Five independent subsamples of the raw household travel survey:
  - Each sample contains **20% of the original HTS trips**
  - Samples are generated using different random seeds
  - Only OD attributes and trip distance are retained

These subsamples are used to simulate survey sampling variability in
downstream experiments.

---

## Reuse guidance

To reproduce the simulation pipeline without access to restricted HTS data,
users may:
- Replace this directory with externally generated or synthetic data
  following the same schema, or
- Use the provided case-study notebooks for qualitative inspection only
